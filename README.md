🎬 Cinematic Story Notepad

About the Project :

Cinematic Story Notepad is a genre-based story development and writing application designed to help writers organize, create, and develop their fictional 
stories in one place. The application provides a dedicated workspace for managing multiple story projects, developing characters, writing screenplays, and 
creating detailed narratives. Its primary objective is to provide a simple yet visually engaging environment for organizing the different stages of storytelling.


Features :

The application allows users to create multiple story projects by providing a title and selecting a preferred genre. Each story automatically adopts a 
genre-specific visual theme, creating a cinematic writing experience. Users can access three dedicated writing sections: Cast, Screenplay, and Story. 
The Cast section allows writers to define characters and their relationships, while the Screenplay section provides space for developing scenes, structures,
and directions. The Story section is designed for writing and maintaining complete narratives. Additionally, the built-in text editor supports customizable 
font styles and text sizes, allowing users to personalize their writing experience.


Genre-Based Themes :

Cinematic Story Notepad supports six different genres: Thriller, Horror, Action, Drama, Periodic, and Sci-Fi. Each genre comes with its own visual theme 
and color combination, which is automatically applied when a story is created or opened. This feature provides a distinctive visual identity for different
storytelling environments.


Technologies Used :

The application is developed using HTML5, CSS3, and Vanilla JavaScript. HTML5 provides the structural foundation, CSS3 handles the visual design, 
responsive layouts, animations, and dynamic genre-based themes, while JavaScript manages application functionality, user interactions, story creation, 
session management, and navigation. Browser LocalStorage is used for storing story details and writing content locally, allowing users to retain their 
saved work even after refreshing the browser. Google Fonts is integrated to provide different typography styles.


Data Storage :

The application currently uses the browser's LocalStorage mechanism to store story information, including titles, genres, timestamps, and content from the 
three writing sections. Since the data is stored locally within the browser, users can access their saved stories on the same browser and device. A backend
server and cloud database are not currently integrated.


Installation and Usage :

To run the application locally, clone the GitHub repository to your computer and open the project folder in Visual Studio Code. Open the index.html file
directly in a web browser or use the Live Server extension in VS Code. Once the application loads, users can create a new story, select a genre, choose a
writing section, and start developing their fictional projects.


Future Enhancements :

Future improvements may include user authentication, backend integration, database connectivity, automatic saving, story editing and deletion, document
export functionality, advanced screenplay formatting, and cloud synchronization. These enhancements aim to transform the current application into a more 
comprehensive story development platform.
